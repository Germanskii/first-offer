# Third-party notices

Dependencies retain their upstream licenses; exact versions are recorded in package-lock.json. In particular:

- pdf-lib: MIT; included notice at `dist/client/vendor/LICENSE-pdf-lib.txt`.
- @pdf-lib/fontkit: MIT; upstream package repository is recorded in its npm metadata and bundled source comments.
- DejaVu Sans: bundled font notice at `dist/client/fonts/LICENSE-DejaVu.txt`.
- Drizzle ORM / Drizzle Kit: Apache-2.0.
- JSDOM and esbuild: MIT.

Bundled vendor code is generated by `npm run build:resume-pdf`. Retain bundled legal comments and the font license when distributing the application.
